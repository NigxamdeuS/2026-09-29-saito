# Nigxam

百の状況質問に、少しずつ答えていくための道具です。性格を類型に分けません。「こういう状況で、どちらに手を伸ばすか」を蓄積し、自分の意思決定モデルを組みます。

同じ種類の迷いを、仕事・親しい人・人前・お金・一人の場面で逆に選ぶと、型が二つに分かれます。材料がそろうまで、二重人格の可能性は判断しません。これは医学的な診断ではなく、解離性同一性症などの疾患を判定しません。

## 仕組み

- 問いは 20 種類の迷い × 5 つの場面 = 100 問。一区切りは五問で、途中で閉じても続きから再開できます。
- 各問の三つの選択肢は、八つの軸(速さ、誰のため、言葉、振れ幅、線、時間、根拠、見え方)のどちらの側か、中間かに対応します。
- **予測**: 答える前に、モデルは同じ軸の過去の答えから次の選択を予測し、記録します。場面を見るモデルと見ないモデルの的中を比べ、選び方が場所に結びついているかを見ます。
- **確かめの問**: 15 問を超えると、十問ごとに前に出た場面を一つ出し直します。三問以上出し直して一致が半分未満なら、分かれ方ではなく揺れとして「判断しない」にします。一致が 6 割未満なら「高い」は「ありうる」にとどめます。
- **可能性**: 保留 / 低い / 判断しない / ありうる / 高い。16 問未満は保留。二つ以上の軸が場面ごとに分かれ、24 問以上で「高い」。
- モデル画面には、軸 × 場面の表、二つの型、軸ごとの寄り、逆を選んだ組、文章でのコピーがあります。
- 記録画面から、選び直し、JSON での書き出しと読み込み、消去ができます。

回答はこのブラウザの localStorage だけに残ります。サーバーへは送りません。

## 動かし方

```bash
npm install
npm run dev
```

開発サーバーは [http://127.0.0.1:43123](http://127.0.0.1:43123) で起動します。

```bash
npm test
npm run lint
```

判定の規則は `src/lib/model.ts`、問いは `src/lib/questions.ts` にあります。
